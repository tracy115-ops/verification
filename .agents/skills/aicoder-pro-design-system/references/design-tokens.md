# Design Tokens (AiCoder Pro)

## Color Palette (Light)
| Token | Value | Usage |
| :--- | :--- | :--- |
| `--bg-base` | `#f5f7fa` | Main outer background |
| `--bg-container` | `#ffffff` | Workspace/Card background |
| `--bg-sidebar` | `#fcfcfc` | Sidebar background |
| `--bg-active` | `#e6f7ff` | Active item background (Blue tint) |
| `--accent-primary`| `#1677ff` | Brand blue for buttons/active text |
| `--text-primary` | `rgba(0,0,0,0.88)`| Primary content text |
| `--text-secondary`| `rgba(0,0,0,0.65)`| Labels and secondary info |
| `--border-base` | `#d9d9d9` | Inputs and buttons |
| `--border-secondary`| `#f0f0f0` | Dividers and group borders |

## Sizing
- **Border Radius**: 6px (Standard), 4px (Small chips), 12px (Modals)
- **Status Bar Height**: 28px
- **Title Bar Height**: 38px
- **Sidebar Width**: 260px

## Shadows
- **Shadow MD**: `0 6px 16px 0 rgba(0,0,0,0.08)` (For dialogs/cards)
