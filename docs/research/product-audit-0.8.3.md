# 0.8.3 主动全面巡检

日期：2026-11-05。[逐项验收矩阵](../quality/acceptance-matrix.md)是持续维护的功能清单，包含正常操作、失败恢复、数据持久化、证据类别及尚未具备的环境。

## 主动发现并修复

1. **窄侧栏无法区分会话**：名称隐藏后仅剩操作省略号，且侧栏/历史列表折叠断点不同。统一为 1150px；窄窗口通过可搜索列表完成选择、右键、重命名、删除和资产入口，新建按钮补充可访问名称。
2. **子弹窗关闭带走列表**：React 关闭/取消事件从重命名窗口传播到会话搜索窗口。仅在搜索窗口自身事件时关闭；900/1120 两种宽度实测改名、资产、删除、Esc 和刷新恢复。
3. **深色流程控件白底**：React Flow 在子节点重置默认变量，覆盖父容器的默认值。改用组件支持的非 default 覆盖变量，小地图、缩放和图线消费当前主题；加入实际背景色断言。
4. **探测结果丢失**：设置组件卸载后状态归零，编排节点还固定显示“尚未探测”。安装快照在本次应用运行内共享，坏响应/重复驱动拒绝并清除旧成功结果；切页复测，刷新不伪造探测。
5. **文件控件样式不统一**：框架、补充包和脚本上传统一为基础文件控件样式，支持深浅主题与焦点提示。
6. **开发模式载入卡住**：初始巡检两次在 `page.goto` 等待超过 90 秒。排除 `.runtime`、Rust `target` 和生成档案的文件监听后，同组巡检正常完成；保留失败记录于运行目录，未通过延长等待掩盖。
