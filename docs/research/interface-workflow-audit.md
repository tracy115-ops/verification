真实调用结果在忽略目录 `.runtime/live-design/final.json`，记录包含真实模型输出和待确认状态；此前 `.runtime/workflow-validation/` 是设计产物回放加真实 Python 执行。两者不能混为一谈。实际待澄清问题包括未知错误优先级、状态查询和非法输入处理，不能靠测试者自行编造预期来通过评审。

## 本轮修改与仍需建设

移除过时的“只能设计评审”文案，完整流程按钮统一叫“调用流程”；待确认卡片前置，报告在流程步骤之前显示实际状态与数量；失败 / 中断 / 待确认在顶部明确显示；用例详情增加需求、前置条件、步骤和预期。评审问题处现在明确说明当前只能取消、修改题目并重启。

下一步优先实现逐条澄清、编辑与重新验证，保留原文、问题、回答、审计和审批摘要，再实现需求 / 因子 / 场景的可编辑结构及下游失效。之后才可声称真实任务从界面顺畅地完成自动分析。完整范围仍需桌面 UI、真实 CLI、真实框架和本地目标联合验收。
