# 页面功能、样式与连续性检查

基线：0.10.2；修复版本：0.10.3。检查以用户操作路径为单位，分别记录界面契约、真实协作服务和原生桌面结果。自动布局检查不能替代目标机器认证、安装与网络验收。

## 本轮修复

- 设置侧栏入口保留上次分区，Agent 的模型/实例输入和框架草稿在导航后保留；不同 Agent、不同框架的输入互相隔离。新建框架草稿可重新选择或取消，不再切换一次就丢失。
- 资产页与运行记录保留浏览状态；资产上下文仍由会话和精确运行 ID 隔离，不把旧筛选或选择用于另一任务。
- 协作页面返回后保留当前项目步骤和场景草稿；隐藏页面停止轮询，重新进入恢复订阅。已有版本冲突检查继续阻止静默覆盖。
- 已有流程但没有旧聊天消息时，不再显示新会话欢迎语。收紧 CLI 探测卡片布局，降低配置页首屏信息负担。
- 修正“测试用例”路由对应资产导航的 `aria-current`，为对话框补离页关闭清理。
- 升级和数据操作分区离页时卸载并执行原有取消清理；不会因为保留其他页面草稿而保留待安装确认。
- 0.10.2 打包失败原因为 NSIS 上游下载 HTTP 504。构建仅对明确的临时 bundler HTTP 429/502/503/504 最多重试两次；编译、权限、图标及其他错误直接失败。

页面保留采用 React 的 Activity：隐藏时保留组件状态并清理 Effects，显示时重新建立 Effects。[官方生命周期说明](https://react.dev/reference/react/Activity)。普通会话任务状态仍由上层任务控制器管理，不会随页面隐藏终止其他会话。

## 证据与限制

`product-audit.spec.ts` 覆盖 15 个页面状态 × 中英文 × 明暗主题 × 900/1500 宽度，共 120 个组合，检查水平溢出、控件边界、无名称按钮和未捕获异常，保存顶部及长页底部截图。配置对话、失败路径及操作连续性由专项用例补充。截图人工复核覆盖会话、编排、资产及设置的代表性窄屏/深色状态；并非逐像素比对全部组合。

补充 `team-layout.spec.ts`：使用真实 HTTP/SQLite 服务创建项目，以明确标记的规则建议填充因子和场景，逐页打开需求、因子、场景评审、用例/脚本和补充建议。五个步骤 × 中英文 × 明暗主题 × 900/1500 宽度，共 40 个布局组合通过，保存全部截图；人工复核了场景编辑的中文浅色及英文窄屏深色界面。本项为标签创建后的补充测试，不修改 0.10.3 应用代码；连同原有四项协作回归，本地共五项协作专项通过。

`desktop-navigation.spec.ts` 使用隔离的实际 Release WebView 与原始 IPC，通过界面导入历史真实设计及 CLI 档案，再检查六个主页面、七个设置分区和跨页状态。历史档案不代表本轮重新调用模型。普通界面测试中的 CLI/升级 IPC 用于契约验证，不能证明内部 CodeAgent、公司代理或安装器在目标机器可用。

[已归档截图与原生摘要](../examples/generated/page-audit-2026-11-08/README.md)。本地 `npm run check` 中 235 项单测通过，Rust 78 项通过、3 项真实网络/PAC 测试显式跳过；真实协作服务 4 项通过。正式状态机另跑 2 项实际 Python 工作流测试；深层订单回归复用已有生成脚本，六个缺陷变体均捕获，参考目标无失败或执行错误，不将脚本重放称作新一轮 Agent 生成。

最终生产构建的 73 项 Playwright 回归全部通过，包括 120 个页面状态的样式矩阵、设置草稿与新建取消、资产/运行记录跨页保留，以及原有升级/恢复失败路径。真实 Release WebView 的 1 项导航专项通过；打包与安装冒烟由新标签流水线继续记录，不以本地编译代替安装验收。

仍需独立推进：设置及离页后的协作草稿的窗口关闭/刷新统一保护；个人主存储事务化与断电恢复；目标环境内部 CodeAgent 长题目；浏览器专属代理及实际跨机器网络；组织身份、TLS 部署和当前未实现的 SSH/WSL 执行。临时导航状态只保留在当前窗口，不承诺重启后恢复未保存配置。
