# 人工与接口补充设计验证

日期：2026-10-29。

## 验证结果

- `npm run check`：100 项 Vitest 测试通过，TypeScript 与生产构建通过；后续表单布局调整另行通过生产构建与针对性交互回归。
- `npm run check:constraints`：268 个源文件通过规模和样式约束。
- 生产包 Playwright：19 项通过；包括人工增加因子、引用关联需求、增加带因子水平映射的场景、刷新恢复和撤销旧用例状态。
- 协作 Playwright：4 项通过。独立 editor 成员以 Bearer 令牌读取基线、HTTP 提交建议；正式因子未被直接替换，editor 合入请求被拒绝，过期提交返回 409；管理员从界面审核合入，接口可读到正式条目。
- Agent 接口指南显示当前项目 URL 与完整贡献 Schema，不包含当前用户或其他成员令牌。
- Tauri debug 桌面包重新构建，实际打开现有游戏平台任务的 10 条真实因子及新增表单。关联需求来自该任务的 10 条真实需求。检查后关闭表单，原有执行证据未修改。

## 修订安全

领域测试证明人工修订保留旧产物与审批，移除下游当前产物、审批和覆盖声明；旧审批摘要不能用于新设计；重新通过覆盖评审后可以生成用例并到达用例评审。修订及历史经会话仓库保存、加载保持一致。重复 ID、错误引用、运行中编辑被拒绝，原任务不会被部分修改。
