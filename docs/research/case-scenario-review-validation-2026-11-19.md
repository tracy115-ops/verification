# 用例断言核对验收

上轮租户配额题目的 S06 场景要求消费已释放的预留时返回 409，且预留和配额都保持不变。原用例在拒绝后重新读取了配额，缺少对预留本身的直接复查。[原始验收](quota-workflow-validation-2026-11-18.md)

0.18.0 在用例评审中提供按场景核对的入口。它使用当前评审节点的设计和用例输入，按本次执行范围过滤用例，并优先定位无关联用例的场景。场景预期与当前用例断言相邻，步骤和前置条件展开查看。生成补充提议的入口会在会话中准备当前场景的指令，评审者可以编辑后发送。

使用上轮 Spec 和已确认设计，将 S06 单独交给生产用例批次函数，通过真实 Codex CLI 生成新用例。用例先保存预留和配额快照，再执行预期返回 409 的操作，最后通过 `GET /holds/{id}` 和 `GET /quota` 比较两份响应。该用例通过结构和关联校验，验收停在用例生成层。

回归检查覆盖重新打开评审、切换场景、展开步骤、窄窗口深浅主题和把当前场景带回会话。关联计数反映已建立的关系，断言是否完整由评审者判断。

本地生产构建、294 项单元测试、代码格式与规模检查通过。评审交互在开发和生产构建通过。用例编辑的中英文及主题回归、两条提议审核回归也通过。[输出和截图](../examples/generated/case-scenario-review-2026-11-19/README.md)
