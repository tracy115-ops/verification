# 桌面真实流程验收

日期：2026-10-28。目标：从桌面会话导入题目，由真实本机 CLI 分析、生成用例与 Python，再经执行确认运行本地接口并形成报告。不能用重放产物或单元测试替代本项。

## 连接故障与修复

- 同一台机器上，直连模型服务请求超时并连续重连；通过当前 Windows 静态系统代理的真实推理成功。
- 原运行层直接继承环境变量，未处理只有 Windows 系统代理的桌面环境。新增回退：显式 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY（含小写）优先；没有显式设置时，读取当前用户已启用的静态系统代理。只设置子进程环境，不修改全局设置或 CLI 的 Provider、凭据和模型配置。
- 自动回退只支持静态 HTTP 代理和按协议区分的 HTTP / HTTPS 项；PAC、自动发现及仅 SOCKS 设置未实现。自动回退时默认绕过 localhost，避免本地框架和 MCP 服务经过远端代理。
- 原先多种失败都显示 `cli_failed`。现在区分连接、认证、限流、模型不可用、进程退出、输入写入、协议和空输出；原生错误只分类，不将可能含凭据的消息直接显示或归档到共享文档。

参数与配置含义核对了本机 `codex exec --help` 及 [OpenAI 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。修复没有清空原生配置。诊断时曾单独排除用户配置以区分干扰，该诊断启动方式没有用于生产驱动。

## 本轮真实任务

输入：[游戏平台黑盒题](../examples/game-platform-blackbox-topic.md)，仅包含题目与外部接口；使用已安装 Codex、`gpt-6.1-terra`、受信任单文件 unittest 框架和 `127.0.0.1:4320` 本地带缺陷服务。

通过 Playwright 连接实际 Tauri WebView，点击新建、选择已保存流程和完整执行范围、粘贴题目并调用。未注入需求、场景、用例或脚本。每个评审节点保留实际截图、任务快照和审批记录；已知框架约定通过界面保存澄清，未知预期保留为排除项，不能算作覆盖完成。

本轮实际生成 10 条需求、10 个因子、17 个场景及 37 条用例。用例分批校验时第三批曾失败；明确传入场景允许引用的需求 ID 后，从失败批次重试，前两批未重新生成。

有一条非法胜者用例缺少拒绝形式的判定标准。通过界面记录原因并排除本次执行，随后独立评审新增的 S13 覆盖缺口；保留原始 37 条草稿，只将 36 条确认为执行范围。排除不等于覆盖，最终报告保留缺口。

首次脚本有 4 个澄清问题，预检停止，未执行 Python。新增恢复入口：针对这些问题保存已确认的接口或框架约定，再由真实 Agent 重新生成脚本；以脚本摘要校验提交，保留旧脚本及回答，每个任务最多修订两次。执行计划或证据产生后禁止走此入口。通过 GET /players/player-a/score 实际确认 JSON 的 score 字段；未约定的状态查询仍不推断。

状态：**实际桌面完整 13 节点已完成**。最终脚本 239 行、44 个测试方法，通过预检后从桌面确认执行：33 通过、11 断言失败、0 错误、0 跳过，记录 100 条请求响应。真实判定 Agent 汇总 8 组候选问题并完成报告。因为保留了 20 条范围排除 / 覆盖缺口，报告为 `inconclusive`，没有宣称完整覆盖。

原脚本不改，经相同原生 Python 执行桥在修复版样例单独对照：44 方法全部通过，101 条请求响应。两次脚本摘要一致；失败断言提前结束方法可能使请求数不同。这项对照不是第二次桌面 Agent 流程。可复核产物见[本轮生成档案](../examples/generated/desktop-flow-2026-10-28/README.md)。

## 会话管理

每行“会话操作”提供重命名、删除。名称去除首尾空白，限制 120 字；删除需再次确认，并说明任务记录与磁盘原始证据的边界。删除当前会话后选择邻近会话，删空后回到新会话页面。运行中阻止管理操作；尚未协调的恢复任务禁止删除。名称、删除与选择回退通过真实浏览器操作及刷新验证。

同样在真实桌面中验证了重命名、取消删除、确认删除、重启选择恢复；只新建并删除空白验收会话，核对原任务快照完全一致。当前会话不再在重启后默认跳回最早的失败记录。

完成后从摘要旁打开独立报告工作区，通过真实下载操作取得 JSON，并核对 8 组候选问题及 11 个失败方法。另从任务资产逐项检查 10 条需求、10 个因子、17 个场景、36 条确认用例，并点击因子关联返回对应原文需求。桌面保留已完成的实际任务，清理了本轮自行创建的空白测试记录；原有会话未删除。
