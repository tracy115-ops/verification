## 验证方法

领域 / 控制器测试覆盖完整节点顺序、四次确认、持久化、执行前后上游变更拒绝、映射错误、Agent 虚构缺陷和错误 / 跳过不转为缺陷。界面检查确认复选框、框架配置保存 / 重载、范围选择和浏览器执行边界。

Rust 测试使用真实进程与 HTTP：预检不导入框架、执行摘要 / 本机 manifest、同 ID 禁止再执行、常量断言没有请求不能通过或报缺陷、框架导入错误、实际断言失败、超时 / 取消、输出超限及连接断开。既有 CLI 进程树测试同时回归。

执行器和框架不是 OS 沙箱；当前不验证任意 SDK、pytest、SSH / WSL 或真实多人远程执行。内部 CodeAgent 未安装在本机，参数兼容性仍需在安装环境确认。
