# 0.11.0 未保存修改验收

本批次处理当前窗口的编辑连续性与关闭/覆盖保护。实现范围见[设计](../design/unsaved-draft-protection.md)；不代表个人主仓库事务化完成，也不认证内部 CodeAgent。

## 操作路径

| 路径 | 检查结果与测试入口 |
| --- | --- |
| 模型/框架输入 → 离开页面 → 数据管理 | 隐藏修改仍阻止清空/恢复，可从列表返回精确表单并聚焦；逐项保存或放弃后解除保护。`unsaved-settings.spec.ts` |
| 模型保存遇到存储失败 | 提示失败并保留输入、继续保护；成功落盘才解除，刷新后读到已保存值。`unsaved-settings.spec.ts` |
| 模型和 CLI 路径同时修改 → 只保存模型 | 路径草稿仍保留；可单独返回和放弃，不撤销已保存模型。`unsaved-settings.spec.ts` |
| 带草稿切换语言 | 表单标签通过消息 key 实时翻译，用户输入原文保持不变。`unsaved-settings.spec.ts` |
| 刷新 → 取消浏览器原生询问 | 草稿与当前页面仍保留。浏览器取消导航不会产生新的加载事件，测试使用有界等待。`unsaved-settings.spec.ts` |
| 框架文件读取未完成 → 放弃/手工改写 → 文件返回 | 迟到结果不能重新创建已放弃草稿，也不能覆盖后续手工输入。`unsaved-settings.spec.ts` |
| 代理编辑 → 分区卸载/重进 → 保存失败/保存中 | 编辑值保留；失败继续保护，保存中禁止放弃及安装，服务器确认后再解除。`unsaved-network.spec.ts` |
| 协作场景编辑 → 设置页 → 关闭/恢复门禁 | 仍有全局保护，返回可继续保存；共享版本冲突保留本地输入。真实 HTTP/SQLite 的 `team.spec.ts` |
| Activity 隐藏及真实组件卸载 | 值和保护都由窗口级仓库继续持有；来源变化时不覆盖本地值，放弃读取最新来源。`shared/drafts/context.test.tsx` |
| 关闭实际桌面窗口 | 原生 close 请求被拦截；取消保持窗口，返回恢复正确输入，明确确认后窗口确实关闭。`desktop-close.spec.ts` |

## 证据类别

- 单测、类型检查、格式及代码规模门禁；纯前端专项的 CLI/升级接口使用受控 IPC 契约，不表示真实认证或安装结果。
- 生产构建页面矩阵包含中英文、深浅主题及 900/1500 宽度；新增修改列表单独检查八种组合。共享项目的四十种内页布局使用真实本地服务。
- 原生关闭专项使用实际编译的 0.11.0 Release、原始 Tauri IPC 和窗口生命周期，分别复核中文浅色及英文深色。[截图与摘要](../examples/generated/unsaved-drafts-2026-11-09/README.md)。

本地已完成 236 项单测、5 项真实协作回归和 78 项 Rust 测试；3 项真实网络/PAC 用例显式跳过。当前窗口草稿不落盘，用户明确允许关闭/刷新、强杀或断电后，不承诺恢复这些未提交输入。已提交的协作写入以服务端修订和审计为准。
