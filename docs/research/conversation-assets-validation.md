# 会话资产归属与紧凑布局验收

日期：2026-10-29。

修正原资产页重复展示页标题、全局任务下拉和范围说明的问题。当前会话是设计工作区的入口，需求、因子、场景和用例均跟随它。旧运行只作为该会话的历史版本，没有运行的会话不会回退到其他任务。

顶部合并为会话标题、返回对话、导出操作及资产切换栏，正文使用剩余高度。移除全局任务选择和对应的废弃消息、样式；条目栏上限 360px，减少宽屏中的水平浪费。左侧新增按会话名称和需求内容搜索的弹窗，适配收窄侧栏并支持键盘关闭。

自动检查使用两个具有不同需求的任务与一个空白会话：从左侧切换后只展示对应内容；空白会话不展示其他任务；顶部不存在重复标题或任务选择框；常规宽度的操作栏高度小于 85px、正文起点小于 150px；900px 窗口无横向溢出。搜索验证需求匹配、名称过滤、选中后上下文切换、自动聚焦和 Escape 关闭。

98 项单元测试与 18 项生产界面测试通过。此前协作补充、共享用例及脚本覆盖功能一并保留；多人回归与真实 CLI 档案见[协作验收](collaboration-coverage-validation.md)。新界面用已有真实运行在桌面中复核，不重新生成或修改其需求、场景和执行证据。

桌面实测的操作栏高 59px，正文从 110px 开始；从左侧切换两个既有真实设计后，分别显示对应的 10 条和 4 条需求。完整流程中的 36 条确认用例自动显示真实预检映射。实际截图：[紧凑资产页](../images/conversation-assets-compact.png)、[用例覆盖列表](../images/conversation-case-coverage.png)、[会话搜索](../images/conversation-search.png)。代码规模检查覆盖 261 个源文件，桌面 debug 构建通过。
