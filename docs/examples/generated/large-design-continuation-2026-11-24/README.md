`summary.json` 保存安全计数和批次摘要，`design.json` 保存已校验的需求与两批产物。原始运行及完整 CLI 公开事件保存在本机 `.runtime/journey-large-continuation/`。共享资料省略实例路径、配置内容、认证信息和私有推理内容。
