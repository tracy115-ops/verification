# 真实 CLI 分批请求样例

2026-10-31 本机使用 `codex-cli 0.164.0`，请求本机已配置的 `gpt-6.1-terra` 模型。由 `agent-runtime` 的 turn 示例执行受管 CLI；输入来自新分析任务模板，关闭 shell 工具、使用只读沙箱。每次原生调用预算 120 秒。

这些是维护者编写的两条规则小夹具，需求基线是输入，不是模型生成的需求分析。`.prompt.json` 为实际发送的任务正文，`.reply.txt` 为真实 CLI 的公开回复，`.design.json` 为应用校验后的结果；本地设计结果含应用添加的批次 ID 前缀。未写入原生会话 ID、登录信息、代理地址或凭据。

`metadata.json` 记录请求、回复 SHA-256、输入字节数与实际耗时。四次请求分别验证：单组设计、存在潜在关联但缺少规则时的候选与缺口、明确状态隔离约束、没有声明关联时的空增量。组间探针单独调用交叉检查阶段，未伪装成已经执行了其余本地批次。

结构与引用校验不等于语义正确或黑盒测试执行。不可观测状态、缺少接口等仍需人工评审；这些小样例也不证明大 Spec 的总耗时一定下降。它们不构成内部 CodeAgent 推理认证，普通自动化测试不会重放真实模型调用。
