# 0.10.2 原生保护副本恢复验收

2026-11-08，本地 `cargo --release` / Tauri custom-protocol 构建，版本 0.10.2。通过隔离 WebView 配置的真实桌面窗口操作；没有替换 Tauri IPC。这里的 Release 指本地优化构建，安装包验收另看对应版本 Actions。

## 输入与操作

输入取自[已归档的真实 CLI 测试设计](../cli-transcript-2026-10-28/README.md)：一条历史任务、一次完成的设计流程及七份产物、四条公开 CLI 调用档案。通过界面导入作为恢复输入，本轮没有重新调用模型或执行 Python 测试。

1. 界面创建 SQLite 保护副本，刷新后重读并导出；核对会话字符串与全部四条记录一致。
2. 新建另一条会话，并从界面删除历史会话；确认其 CLI 记录已清除。
3. 选择旧副本预览、确认恢复，自动保护当前数据并重新载入；核对整个会话/运行/产物 JSON 与原始输入一致，IndexedDB 中四条 CLI 记录逐字段一致。
4. 选择恢复前副本再次恢复，核对回到另一条会话，历史 CLI 记录重新清为零。

- [撤回到恢复前数据的预览](restore-preview-2.png)：另一条会话，没有历史运行及 CLI 记录。

原始输入文件与带本机路径的审计摘要仅保留在忽略的 `.runtime/native-shadow/`。数据库在操作前确认不存在；测试后核对整文件摘要再清理测试专用副本。上述输入为历史真实记录，恢复测试会话封装由测试脚本构建；不代表本轮新完成了一次 Agent 测试设计。

这不是断电、强杀、真实磁盘满或跨存储原子恢复验收。主仓库仍是 localStorage / IndexedDB，保护副本为 SQLite；仅保留最近两份，不提供永久撤销历史。
