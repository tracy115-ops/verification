Black-box room capacity verification. The framework submits POST /rooms as player-a with JSON {maxPlayers,mode,ranked}. mode is fixed to duel; ranked is fixed to false. This task contains exactly four independent tests: maxPlayers=2 returns HTTP 201; maxPlayers=8 returns HTTP 201; maxPlayers=1 returns HTTP 400; maxPlayers=9 returns HTTP 400. Each test uses a fresh framework fixture and creates no shared room. Only assert these four HTTP status results. Other inputs, authentication, missing fields, concurrency, response fields and dependency faults are outside this task scope.
