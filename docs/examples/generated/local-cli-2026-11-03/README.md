# 本机真实 CLI 验证记录

日期：2026-11-03。输入为维护者编写的[四个容量值黑盒设计题](source-spec.md)，没有被测系统源码。使用本机已配置 CLI，通过当前 `agent-runtime` 原生进程桥与生产工作流引擎调用模型。

## 文件与来源

- `metadata.json`：CLI 版本、请求模型标识、耗时、字节数、状态、请求/回复 SHA-256，以及两条设计流程的计数。
- `*.prompt.txt`：实际请求正文。`*.reply.txt`：实际公开回复，失败无正文时为空。
- `*.diagnostic.json`：原生安全计数与最后状态；不含思考正文、凭据、原生会话 ID 或代理地址。
- `codex.artifacts.json`、`claude.artifacts.json`：通过应用校验的需求、设计和用例产物。
- `codex.reviews.json`、`claude.reviews.json`：三个正式评审关口及范围项的逐条处理理由。

原始模型内容未重写为预制产物。归档来自基于 `e4376ce` 的修复工作树，验证时桥接程序版本仍为 0.6.3；之后发布为 0.6.4。模型标识是请求标识，Claude 的 `sonnet` 由其本机原生配置解析，不据此认证上游实际模型身份。
