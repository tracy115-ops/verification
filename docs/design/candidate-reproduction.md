# 候选问题复现资料

## 使用方式

在会话或运行实例中打开报告，选择候选问题，点击“导出复现资料”。导出的 JSON 以 `formatVersion=1`、`kind=candidate-reproduction` 标识格式。选择的候选用于定位关联方法，`scope=approved-suite` 表示资料携带完整已批准脚本和方法映射。

资料包含原始 Spec、已确认需求、设计、用例、脚本、框架源码、记录的目标配置、Python 版本、原执行结果和请求响应，以及该候选的人工复核历史。执行和源文件摘要便于核对来源，复跑前应按实际测试环境准备目标及原框架所需的初始化条件。

## 一致性检查

导出要求报告、执行计划、执行 ID、脚本用例映射及失败方法相互对应，需求和用例引用可解析。还会校验结果计数，以及脚本、框架源码的 SHA-256。资料不足时阻止导出并在报告中显示原因。

输入在导出开始时保存快照，异步计算摘要期间发生的界面切换或数据更新不会混入本次资料。导出保留用户脚本和源码原文，数据结构明确选择复现资料字段。个人 CLI 的登录、Provider 和启动配置由工作台单独管理。

## 应用内复跑

0.21.0 已支持[应用内逐次复跑](reproduction-runs.md)：每次使用新的执行 ID、独立工作目录、预检和人工目标确认，保存实际结果并按方法汇总观察。原报告与人工复核记录保持原样。无人值守批量、证据压缩和最小化复现仍待后续实现。
