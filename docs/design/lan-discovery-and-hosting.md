# 局域网发现与桌面托管

## 使用流程

1. 主持人在桌面“设置 → 局域网协作”填写名称、网页端口，点击“启动并允许局域网访问”。本机需安装 Node.js 24 或更新版本。
2. 打开列出的网页地址，用本机管理员令牌登录，在“项目协作 → 成员和角色”中为每人创建个人令牌。
3. 同事在桌面“项目协作”点击“扫描局域网”，选择服务并在浏览器加入；也可以直接使用主持人分享的地址。登录使用个人令牌。
4. 成员共同维护测试因子、场景、负责人、讨论和评审，每 5 秒同步。并发写入检查修订号，冲突不覆盖本地草稿。

个人会话、CLI 调用档案和执行工作流保留在各自设备。当前共享项目设计、用例、增量建议、覆盖声明及脚本映射，支持成员导入的执行记录；不远程驱动主持人的 CLI 或执行上传的测试。静态方法核对需要主持人安装 Python，服务只启动固定 AST 解析器。详细规则见[增量协作与脚本覆盖](collaborative-contributions-and-script-coverage.md)。

## 实现边界

Tauri 管理固定协作服务子进程，启动时检查 Node 版本，限制启动等待时间并监督进程。停止服务或关闭应用回收自有进程；项目数据库保留。服务按需启动，不默认监听局域网，不修改防火墙。

构建运行 `npm run build:desktop`，将 `server/index.ts` 及依赖打包到 `.runtime/team-bundle/server.cjs`，同时复制生产网页。Tauri 将这些资源放入 `collaboration/`。`npm run tauri dev` 会先生成资源再启动开发服务；直接执行桌面 Cargo 检查前需先运行 `npm run build:desktop`。发布调试程序时应保留同级资源目录。打包采用 [Rolldown 的 Node 平台及 JavaScript API](https://rolldown.rs/guide/getting-started)。

发现使用 UDP 4319 的自定义版本 1 协议，并非 mDNS。扫描发送请求关联标识，除全局广播外也探测活动 IPv4 网卡的子网广播地址，避免 VPN 路由独占发现。服务回复名称、实例 ID 和 HTTP 端口；客户端以报文来源地址构造加入地址，校验版本、关联标识及长度，最多接受 32 个实例，同实例优先显示私网地址。服务限流，不广播访问令牌或项目数据。发现受网络广播、子网和防火墙影响，因此始终保留手动地址入口。HTTP 默认端口 4317，可修改。

浏览器使用同源 HTTP API、个人 Bearer 令牌和现有服务端角色校验。本机管理员令牌保存在应用数据目录的私有文件，界面默认遮盖；发现报文不含令牌。HTTP 适用于可信局域网，其他网络需在外层配置 HTTPS。SSO、逐项目授权与令牌撤销仍属于后续范围。

## 数据与故障

数据库在系统应用数据目录的 `dev.verification.workbench/collaboration/` 中，沿用 SQLite 事务及历史快照。管理员令牌文件与数据库同目录，不进入仓库；有界启动诊断写入本机 `startup-error.log`，不展示原始错误堆栈给其他成员。

Windows 的扩展格式路径在传给 Node 前转换为普通路径，避免入口解析 `EISDIR`。端口占用、Node 缺失、资源缺失、启动超时和扫描失败返回稳定错误码。启动失败不生成运行中的假状态，扫描不可用时仍可通过网页地址加入。
