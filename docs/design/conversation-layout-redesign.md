# 对话与任务三栏布局

2026-10-28。用户明确偏好类似 Codex 的布局，保留左侧导航、中间对话、右侧任务。之前的拥挤来自多种内容同时摊开，不应通过改成上下大卡片解决。

## 默认视图

- 左栏：导航、新建会话、历史会话列表和底部设置。点击历史会话切换到对应对话；新建与列表不再占用中间区域。
- 中栏：会话标题、消息和底部输入框；长题目显示摘要，可展开原文。正文最大阅读宽度约 800px，运行配置保持紧凑，持续可见的输入框不占据半屏。
- 右栏：默认 360px，可拖动分隔线调整至 280–640px；同时为对话保留至少 380px（窄屏改为上下排列）。宽度与收纳状态分别保存，窗口变窄时限制实际宽度，不覆盖原有偏好。分隔线支持方向键每次调整 24px、Home / End 到边界、双击恢复默认。默认展示需求、因子与场景、用例与脚本、测试执行、分析与结果的阶段概览，突出当前阶段；阶段可以展开查看实际节点。历史产物按需展开，不将所有长表单和结果同时摊开。此处是阶段概览，完整依赖图仍由编排编辑器承载。
- 详细评审：通过“打开评审工作区”进入宽约 1000px 的独立对话框，展示问题、回答、因子 / 场景 / 用例及确认动作。保留返回对话入口，避免在窄栏塞长表单。

## 操作路径

配置 Agent / 框架 → 保存流程 → 中间对话输入题目并调用 → 右侧显示当前阶段 → 打开宽评审区处理澄清或范围排除 → 继续 → 右侧显示执行结果与问题数量 → 在任务资产中逐条追溯。

运行状态、设计覆盖和测试结论分别展示。失败时突出失败阶段和重试动作，不根据泛化错误猜测登录或模型配置有问题。原始题目与历史产物不因布局变化改写。

## 步骤产物与操作反馈

右栏只显示阶段、节点、真实状态及产物入口，移除底部将所有正文串起来的“本次产物”。每个已产出节点显示数量，例如“10 条需求”“10 个因子 · 17 个场景”“36 条用例”；阶段旁提供直达最新产物的入口。点击产物不会顺带展开阶段。

产物在独立宽工作区打开，可以切换步骤；需求、因子、场景、用例复用可搜索的条目列表与详情，通过真实 ID 导航到原文和关联场景。草稿与确认集分别可选，不混淆排除用例和执行范围。脚本可查看 / 下载，执行计划展示目标与摘要；证据按方法选择，默认筛选失败断言，只显示当前方法的请求响应。澄清、排除与历史脚本统一放入“复核决策与修订”，不占用右栏正文。

保存、导入、导出、设置等操作反馈使用浮动 Toast，不改变内容区高度。成功提示 4 秒后消失，鼠标悬停或键盘聚焦时暂停；错误提示可手动关闭。同一反馈重复触发会重置计时，切页清理旧反馈。图校验详情仅在编排页显示；任务运行错误仍跟随具体任务，不能用短暂提示替代。
