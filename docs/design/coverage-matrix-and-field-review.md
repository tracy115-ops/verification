# 覆盖矩阵与协作字段评审

## 当前实现

矩阵绑定所选会话中的当前运行，历史运行入口仍保留其固定产物。按产物类型优先读取已确认版本，缺少时使用草稿，与现有资产详情保持一致。

每条需求关联显式引用它的因子、场景和用例，同时列入引用其场景的用例。通过集合过滤避免一个用例在同一需求重复计数；跨需求关联允许分别展示。因子、场景或用例缺失，或者用例尚未全部映射脚本时，进入结构缺口筛选。执行失败在独立证据列展示，不与设计缺口混为一谈。

覆盖状态复用个人用例覆盖判定，分别统计声明但未映射、已映射及匹配执行证据通过。关联完整不证明语义完整；原文遗漏、不可达组合及因子水平组合覆盖仍需要人工和 Agent 评审。

协作补充采用顶层字段差异表，忽略未变内容和对象键排序差异。新增与删除保留在表中，数组保留原有顺序。常用字段本地化，复杂嵌套对象保留结构化文本，原始对象可展开。冲突仍由提交前基线与当前服务端版本比较；此视图不绕过既有权限或逐条接受流程。

## 后续边界
