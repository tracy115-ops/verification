# 需求引用校验与恢复

原文引用不能使用相似句或模型改写替代。校验优先精确匹配；精确匹配失败时，仅合并连续空白进行唯一定位，再按原文字符偏移恢复真实片段。格式校正不修改源 Spec，不采用编辑距离、数字替换或近似语义匹配。多个候选继续返回歧义错误。

结构与 ID 校验通过、仅引用校验失败的生成结果保留为待验证草稿，节点仍失败，下游不会自动继续。用户可以选择问题条目，复制能够唯一定位的原文片段。保存会重新验证全部引用、更新草稿摘要、记录修复审计，并进入原有需求人工评审；不会自动批准。

旧版任务缺少草稿时，可从匹配 runId、sessionId、turnId 的 CLI 回复记录恢复。只恢复完整结构化 JSON，不将部分文本猜测成需求。若用户选择继续调用 Agent 重试，携带有限的引用错误样例及总数，要求复制原文；不增加自动模型重试循环，也不设人工重试次数上限。

验证覆盖格式差异、数字改写拒绝、歧义拒绝、草稿保留、修复后零新增 CLI 调用进入人工评审，以及生产界面从旧记录恢复并修改引用。长超时记录同时与原生请求边界保持一致，避免回复存储因旧上限被拒绝。
