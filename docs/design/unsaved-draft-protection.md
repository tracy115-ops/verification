# 未保存修改与关闭保护

版本：0.11.0。范围为当前窗口的输入连续性和关闭/覆盖保护，不代表个人数据主仓库迁移完成。

## 行为

- Agent 模型、CLI 实例路径、新 Provider、测试框架、更新代理、协作场景的未提交值由窗口级草稿仓库持有。切换 Agent、设置分区、主页面及组件卸载后，草稿与未保存状态仍保留。
- 每个表单保留自身保存与验证规则；保存失败保留输入，成功才清除登记。放弃只恢复该表单的最新已保存内容，不写入配置或协作项目。
- 保存异步进行时保留保护并锁定放弃操作，防止通过“放弃”提前解除更新/恢复限制。失败后解锁并保留草稿。
- 已保存来源在编辑期间变化时，设置表单保留本地值并提示冲突，要求基于最新内容重新编辑；协作场景继续用开始编辑时的项目修订提交，服务端版本冲突不会静默覆盖。
- 测试框架文件读取也纳入保护。放弃、新建取消或后续手工修改后，迟到的读取结果不能重新覆盖输入。

## 页面与操作

数据管理和升级页展示未保存修改的处理入口。列表可返回具体设置表单或协作页面，也可逐项放弃；不会替用户批量保存未经验证的配置。仍有修改时阻止恢复、清空和安装交接，安装前及保护副本恢复前再读取仓库的最新状态。

浏览器刷新/离开使用 `beforeunload` 原生询问。桌面关闭使用 Tauri 的窗口关闭请求：列出隐藏页面中的未保存项，并提示流程未保存或任务仍在执行。取消继续保留窗口；明确“不保存并关闭”后才销毁窗口。异步保存未结束时须先等结果。只新增主窗口的 close/destroy 权限，不增加文件系统或任意进程权限。

## 模块与生命周期

`shared/drafts/store.ts` 只管理内存条目与订阅；`context.tsx` 为表单提供值、基线、修改、放弃和保存状态。工作台负责页面定位、覆盖操作门禁及窗口关闭；页面隐藏导致的 Effect 清理不再移除保护。

仓库不写 localStorage、IndexedDB、日志或备份，不自动应用无效配置。草稿键隔离表单、Agent、框架以及协作服务/项目/场景。放弃保存中的条目在仓库层也会被拒绝，不能只依赖按钮禁用。

表单类别保存语言无关的消息 key，条目名称和输入值保留原文；切换界面语言不会固化旧标签，也不会重写用户内容。原生窗口关闭请求使用 [Tauri 窗口生命周期接口](https://v2.tauri.app/reference/javascript/api/namespacewindow/#oncloserequested)。

## 边界

用户明确同意刷新或关闭后，内存草稿会丢失。强杀、断电后的未提交草稿恢复不在本版本内。已有会话/CLI 档案的持久化和保护副本规则保持独立。关闭不撤销已经提交的服务端请求；协作写入仍以服务器修订和审计记录为准。该批次不认证内部 CodeAgent 或公司代理环境。

## 验收

单测检查 Activity 隐藏、真实卸载后恢复与来源冲突。界面专项覆盖隐藏修改阻止覆盖、保存失败、刷新取消、文件读取迟到、代理跨卸载保留、保存中不能放弃以及明暗主题/中英文/窄屏。协作回归检查离开项目页后仍有全局保护；独立 Release 原生专项通过真实窗口 close 请求验证取消、返回输入和显式关闭。模拟 IPC 与实际原生窗口结果分别记录。
