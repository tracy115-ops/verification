# Verification Workbench 0.1.3

修复 Windows 内部 CodeAgent 安装漏检 / Fix Windows CodeAgent launcher detection.

- 支持 `codeagent.bat` 与自定义 `codeagent.cmd`，包括带空格的安装目录。
- 保留 npm 入口直接调用；补充 cjs 入口和相邻 Node 运行时识别。
- 合并桌面进程 PATH 与 Windows 最新用户／系统 PATH，探测、help 校验和调用使用同一搜索策略。
- 接受 `1.2605.05.02 (codeAgentCLI)` 等内部版本文本。
- 区分未找到入口、启动失败、版本命令失败、无输出和超时；探测超时回收子进程。
- Windows batch 回归验证版本、help、JSON 参数、空参数及标准输入原样传递。

Supports Windows CodeAgent .bat and custom .cmd launchers in paths with spaces, refreshes discovery from current Windows PATH configuration, and distinguishes launcher discovery from version-probe failure. Batch forwarding is regression-tested with JSON, empty arguments and stdin.

内部环境的真实 CLI 与模型推理仍需部署环境验收；本地使用明确的批处理夹具，没有调用内部模型。安装程序未签名。Node.js 24+、Python 及 Agent CLI 按使用能力单独配置。

The internal CLI and model still require deployment-environment acceptance. Local verification uses an explicit Windows batch fixture. The installer is unsigned; runtime prerequisites remain separately installed.
