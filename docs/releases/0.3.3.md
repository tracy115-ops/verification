# Verification Workbench 0.3.3

- 在线升级通过 Windows Shell 启动校验后的 NSIS 安装包，Windows 接受启动后才退出工作台；启动被拒绝时记录失败并保持工作台运行。
- 使用 `/UPDATE /S /R`，避免被动模式下的语言选择窗口阻塞，安装结束请求自动重启。安装目录仍为当前程序目录，完整目录参数置于最后。
- 打包验收改为真正检查安装器自动重启：包含空格的安装目录中覆盖安装后，等待新应用出现并验证持续运行，不再手动启动后宣称自动重启通过。

此修复针对升级交接和隐藏交互风险；用户环境的具体中断原因尚未取得安装器错误证据。旧版本更新器自身不会被远端包提前修复，旧版在线升级失败时需先手动安装本版。此轮仍是同版本覆盖安装测试，不等同于跨版本业务数据迁移验收。
