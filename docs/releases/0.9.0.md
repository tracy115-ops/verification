# 0.9.0

- 统一可运行能力：非 native Provider 作为配置草稿保存，在会话及节点中明确禁用运行选择；旧绑定仍由运行边界校验。
- 需求评审提供分批预估及首次设计预算，批准时记录额度；继续分析可调整每轮 1–64 批次，默认 16。预算耗尽保存检查点并暂停，恢复不重复已完成批次，不限制总继续次数。全部调查完成前不进入设计评审。
- 设置增加主动短对话连通检查，使用已保存的 CLI 路径、Claude 配置目录和模型，CodeAgent 保持内置模型。明确提示可能产生费用、60 秒超时、支持取消；保存配置后清除旧结果，迟到回复不恢复陈旧成功。
- 连通结果在本次应用内共享至设置与节点状态，展示检查时间；只证明短对话有效，不代表结构化分析、所有模型或目标环境已验收。
- 修复分析重试控件与引用修复控件使用相同 React key 导致修复表单残留的问题；全量界面回归发现，修复后该路径及连通测试复跑通过。

验证：[连通检查验收](../research/cli-connection-0.9.0.md)。本机原生 Claude 通过固定短请求，实际使用本机继承环境中的自定义网关，不证明真实 GLM 服务或用户内部实例可用。常规测试使用离线 IPC，不调用付费模型。预算恢复、无效值、认证失败、取消及配置变更竞态均有回归。

未完成：风险关系排序、真实费用预算、任务准备清单及个人 SQLite 迁移仍按[产品计划](../roadmap/testagent-product-plan-2026-11.md)推进。现有全组合调查范围保留，不将预算暂停或短请求成功当作覆盖完成。
