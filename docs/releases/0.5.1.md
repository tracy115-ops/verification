# Verification Workbench 0.5.1

- 需求原文引用可对唯一匹配的空白和换行差异做格式恢复，最终仍保存原文中的真实片段；文字改写、数字差异及多处匹配继续拒绝。
- 引用校验失败时保留结构化需求草稿，显示待修复条目，可修改引用并进入原有需求评审，不重新调用 CLI，也不跳过人工确认。
- 旧任务可从同一次 CLI 回复记录恢复草稿；修复记录包含前后摘要和引用变化。人工重试仍留在同一任务，并携带上次引用校验反馈。
- 同步 CLI 回复记录的超时校验上限，允许保存和恢复已配置的长超时调用。

修复只能保证引用确实存在且唯一，不证明需求摘要或验收点的语义正确；仍需评审。无法从已删除或非结构化回复恢复的任务会明确提示，不虚构草稿。

本地验证通过：128 项前端测试、3 项生产构建界面测试及 2 项原生 Python 工作流集成测试。界面回归包含从旧 CLI 记录恢复（1800 秒请求）、修复引用、保持同一任务且无新增模型调用进入人工评审；该结果不代表用户内部模型分析内容已完成验收。
