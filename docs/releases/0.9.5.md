# 0.9.5 — 修复窄窗口资产导航

英文界面在 Linux CI 的 900 像素窗口中，资产页的 Coverage matrix 按钮超出了可视范围。标签栏现在在空间不足时换行，保留全部入口；共享该标签栏的产物视图也采用同一布局。

新增宽字体条件下 760/900 像素的回归，验证每个按钮均在容器内，并能进入覆盖矩阵再返回需求。该回归在修改前复现失败，修改后通过；原有越界审计没有放宽。中英文、深浅主题生产界面巡检与 `npm run check` 通过。

主分支 Linux CI 在界面失败时会保留 Playwright trace 和截图，便于直接定位下一次跨平台差异。此改动不涉及 CLI 凭据、流程产物或自动升级安装逻辑。

真实 Claude 设计流程续验还发现“声明无缺口但遗漏因子水平映射”的输出。覆盖评审保持阻塞；现已补强设计提示中的自检规则，明确固定输入和夹具前提也需要关联，不允许删水平或编造场景来掩盖缺口。真实增量修复及离线回归见[验收产物](../examples/generated/live-claude-design-2026-11-06/README.md)。这不保证所有模型输出都完整，人工评审与阻塞校验仍保留。

续验最终通过：5 次真实调用、3 个审计批准节点，设计流程 completed，得到 7 条需求、7 个因子、4 个场景及 4 条用例。通过 213 项前端单测、60 项生产界面测试、8 组开发版巡检；窄窗口修复后的 Linux 前端和 Windows Rust CI 均成功。尚未声称本机原生窗口完整点按、内部 CodeAgent 推理或本轮目标执行验收通过。
