# 0.8.5

- Agent 的 CLI 实例配置改为自动扫描和下拉选择。扫描当前进程与系统 PATH、已知工具入口及 CodeAgent 常见安装位置，保留多个安装实例与启动包装脚本。
- 增加原生启动文件、Claude 配置目录选择器；取消选择保留原值，可一键恢复自动发现及配置继承。
- 手动路径编辑收至高级设置。浏览器环境明确提示无法扫描本机或打开桌面选择器。
- 扫描只读取候选入口，不执行安装程序、不调用模型，不声称已验证登录；扫描失败保留现有绑定。

验证：本机 Rust 扫描实际发现 Codex、Claude、Pi；多实例、包装脚本和请求链路契约通过。界面交互覆盖扫描选择、浏览取消、保存与刷新恢复，并检查开发/生产、深浅主题与窄窗口。原生文件选择器通过 Tauri 官方对话框插件接入并完成 Rust 编译检查；本轮未完成原生窗口交互验收，不能将离线 IPC 测试视为系统文件选择器实测。
