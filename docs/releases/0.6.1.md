# Verification Workbench 0.6.1

- 对话框支持 Enter 发送、Shift+Enter 换行；中文输入法确认选字不会触发发送。
- 普通对话和流程调用在本地接收消息后立即清空输入框，不再等待 CLI 回复结束；发送前校验失败保留草稿。
- 分析调用展示“单次分析”或批次进度，并显示实际请求的 UTF-8 字节数。
- 未建立分批检查点的失败分析节点可“改用分批分析重试”，沿用原会话、任务和评审；选择可以保存和恢复，已有批次继续原计划。

分批不保证缩短总耗时。内部 CodeAgent 未安装，本次不能证明其初始化后等待问题已解决。

本地验证：137 项 Vitest 测试、6 项生产构建 Playwright 交互测试、2 项真实 Python 工作流集成测试通过。界面测试仅模拟原生 CLI 边界，不代表内部 CodeAgent 推理验证。
