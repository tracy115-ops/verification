# Verification Workbench 0.1.0

首个编号发布 / First numbered release.

- 本地 Agent CLI 会话、版本探测与已保存验证流程调用。
- Agent 回复等待动效、实时文本显示，以及完成／失败／取消后的状态收敛。
- 按会话保存需求、测试因子、场景、用例、脚本及执行证据。
- 本地 Python 黑盒测试执行、结果分析与报告。
- 桌面端及浏览器加入局域网协作：身份与角色、分工、评审、补充建议和脚本覆盖映射。
- Windows x64 NSIS 安装程序，包含协作服务与网页资源。

## 使用前提与限制 / Requirements and limitations

安装程序未签名。托管协作服务需 Node.js 24+；测试脚本检查与执行需 Python；Agent CLI 及其认证单独安装配置。缺少 WebView2 时安装程序需要联网下载。

已验证同机多桌面客户端协作；跨机器网络、防火墙、内部 codeagent 环境仍需部署环境验收。SSH / WSL 执行尚未集成。版本号不代表所有架构规划均已完成。

Unsigned Windows x64 installer. Node.js 24+ is required for collaboration hosting, Python for script validation/execution, and separately configured local Agent CLIs for inference. WebView2 may require an online download. Cross-machine deployment and internal codeagent integration require environment-specific acceptance; SSH / WSL execution is not integrated.

附件包含安装包、`SHA256SUMS.txt` 和 `build-info.json`，可核对应用版本、源提交及构建编号。
