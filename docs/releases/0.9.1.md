# 0.9.1

- 原生 Agent 配置改为一次只显示一个 Agent，按“确认模型 → 保存 → 测试已保存配置”排列，去除四套重复表单。
- CodeAgent 显示内部管理模型，无模型输入框。其他 CLI 明确要求实际模型 ID，并说明不能将显示名称直接当作 ID；当前尚无自动列出模型功能。
- 模型未保存时禁止测试；切换 Agent 保留本页未保存模型草稿。实例选择仍可扫描/浏览，默认收起，通常保持自动发现即可。
- 生产界面测试使用独立端口并禁止复用现有服务，避免其他本地项目占用端口后误测。

验证：210 项单测、59 项生产界面回归通过；开发模式的实例选择回归通过。包含保存、连通失败与结果失效、切换草稿、多实例选择，以及 900/1500 宽度的深浅主题截图。界面测试的连通回复来自离线 IPC，不代表内部账号实际可用；真实 Claude 短调用结果见 [0.9.0 验收](../research/cli-connection-0.9.0.md)。配置顺序见 [使用步骤](../workflows/agent-setup.md)。
