# Verification Workbench 0.1.2

修复 Windows 并发测试夹具冲突 / Fix Windows concurrent fixture collisions.

- 修复测试夹具仅按系统时间命名目录导致的并发撞名、跨测试文件干扰和清理时二次 panic。
- 临时目录使用进程 ID、原子序号及独占创建；已有目录绝不复用。
- 增加固定相同时间戳创建 32 个目录的回归，保留连续三轮执行测试门禁。
- 包含 Agent 回复等待动效、实时文本，以及完成／失败／取消后的状态清理。
- 保留应用、Tauri、Rust、锁文件及发布标签一致性检查，使用 Rust 1.97.0 和 release 编译模式。

Fixes time-based temporary-directory collisions that caused concurrent native tests to share files and panic during cleanup on Windows. Adds deterministic collision regression coverage and retains repeated execution-contract checks. Includes Agent reply activity and streaming feedback.

历史 `v0.1.0`、`v0.1.1` 标签构建失败，未发布安装包；原标签保留用于追溯。

安装程序未签名。协作托管需 Node.js 24+，测试脚本需 Python，Agent CLI 及认证单独安装配置。跨机器网络和内部 codeagent 需环境验收；SSH / WSL 执行尚未集成。

Unsigned Windows x64 installer. Node.js 24+ is required for collaboration hosting, Python for script validation/execution and separately configured local Agent CLIs for inference. Cross-machine and internal codeagent deployment require environment-specific acceptance; SSH / WSL execution is not integrated.
