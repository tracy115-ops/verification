# Verification Workbench 0.3.0

- 验证资产新增当前任务的覆盖矩阵：需求、因子、场景、用例、人工声明、脚本映射和执行证据并列展示。
- 支持搜索需求、仅看设计或脚本缺口，以及点击条目 ID 跳转到原有详情和编辑入口。
- 协作补充评审按字段显示增加、修改和删除内容，隐藏未改变字段；原始 JSON 收进详情，保留冲突检查与逐条合入。

矩阵反映显式关联与已有证据，不认证语义覆盖完整。人工声明不计为脚本映射或执行通过；执行失败独立展示。矩阵目前用于个人任务资产；团队共享项目继续使用原有场景、用例和覆盖声明工作区。

验证：119 项前端单元测试通过；生产构建下 3 项资产、覆盖矩阵和覆盖声明交互测试通过；4 项多人协作测试通过。截图来自归档任务和协作测试夹具，不代表本轮调用模型或真实业务接口。
