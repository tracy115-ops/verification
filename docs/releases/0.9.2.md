# 0.9.2

- Codex、Claude 配置增加“读取已有模型配置”，显示候选模型和来源，用户可采用到草稿，再保存和测试，减少查找模型 ID 的操作。
- Codex 只读 `CODEX_HOME` 或用户目录的 `config.toml` 顶层 `model`。Claude 支持已选择目录、`CLAUDE_CONFIG_DIR` 或用户目录的 `settings.json` 中 `model` / `env.ANTHROPIC_MODEL`，以及进程 `ANTHROPIC_MODEL`。
- 不读认证文件，不返回配置全文或解析错误原文；限制文件大小，读取不会启动 CLI、修改配置或调用模型。配置来源变化后丢弃旧页面的迟到结果。

候选不等于可用模型列表；启动包装脚本、项目设置、组织策略及 CLI profile 可能覆盖用户默认配置。CodeAgent 保持内置模型；Pi 暂不提供读取入口。

验收：211 项前端单测、40 项 Agent Rust 测试通过；模型候选采用、保存测试和多实例选择的两项生产界面回归通过。Rust 桌面编译检查通过。本机只读验证确实找到 Codex 默认模型，没有借助模型调用。认证/内部环境支持范围不随读取候选而扩大。

配置步骤见[使用指南](../workflows/agent-setup.md)。文件作用域参考 [Claude 官方设置说明](https://code.claude.com/docs/en/settings)及 [Codex 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)；当前实现读取上述明确字段，并不模拟全部 CLI 配置优先级。
