# 0.13.0 — 设计评审与补充闭环

- 设计缺口分为待处理、待生成及已处理；显示已保存的澄清答案和排除理由。排除不计作覆盖，尚未生成用例时不显示“通过 0/0”。
- 补充需求没有场景或直接关联用例的检查；当前范围之外的草稿用例不计入覆盖矩阵。
- 覆盖评审和覆盖矩阵中的缺口可带回原会话，保留已有输入，按当前运行生成待审核的设计修改提议。
- 修复节点重排后设计修改可能遗漏下游失效的问题。旧用例和确认进入历史快照，其他未合入提议标记过期。
- 移除已不符合实现的“最多 10 次设计修订”错误提示。

本次补充入口针对因子和场景，不直接修改用例；结构关联检查不代表组合或业务行为覆盖完整。设计见[评审闭环](../design/design-review-quality-loop.md)，验证范围见[验收记录](../research/design-review-loop-validation-2026-11-09.md)。
