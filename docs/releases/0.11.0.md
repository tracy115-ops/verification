# 0.11.0 — 未保存修改与桌面关闭保护

设置和协作的未保存输入改由当前窗口统一保留。模型、路径、Provider、框架、代理及协作场景在切换页面或分区后可继续编辑；保存失败保留输入，成功才解除保护。

升级和数据管理可查看待处理修改、返回对应条目或逐项放弃。未保存修改会阻止安装、恢复和清空；保存中的请求完成前不能放弃来解除门禁。框架文件读取迟到也不会覆盖已放弃或新输入的内容。

浏览器刷新增加全局保护，真实桌面窗口关闭时可查看隐藏页面的修改并取消关闭。明确同意不保存后才能关闭；只为主窗口增加生命周期权限。当前保护不提供断电/强杀后的内存草稿恢复，也不会自动保存无效配置。

设计及验收边界见[未保存修改与关闭保护](../design/unsaved-draft-protection.md)。该批次不认证内部 CodeAgent 或公司代理。

本地完成 236 项单测、83 项生产界面回归、5 项真实协作回归、78 项 Rust 测试（3 项真实网络/PAC 显式跳过）及实际 Release 关闭专项。远端全量检查、安装与升级由该标签流水线核对。[操作验收与截图](../research/unsaved-drafts-validation-2026-11-09.md)。

从旧版本升级前先保存其窗口内的未提交输入；新保护机制从运行 0.11.0 起生效。
