# Verification Workbench 0.1.1

Windows 发布流程修订 / Windows release pipeline corrections.

- 包含 0.1.0 的 Agent 等待动效、流式对话、黑盒验证与桌面协作功能。
- 固定 Rust 1.97.0，与本地验证工具链一致，避免 CI 的浮动 stable 改变编译环境。
- 原生测试保留完整日志；执行运行时额外连续测试三轮，任一失败即中止发布。
- 普通测试夹具允许 30 秒启动及执行预算；超时取消回归保持 1 秒。
- 版本、标签、锁文件、安装包与 SHA-256 构建信息校验。

`v0.1.0` 打包失败，未发布安装包；保留原标签以追溯。本次使用新 PATCH 标签，不覆盖历史构建。
