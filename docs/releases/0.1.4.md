# Verification Workbench 0.1.4

修复可复用 Agent 配置的检测状态 / Synchronize reusable Agent profile discovery status.

- 本机 CLI 配置关联上方对应驱动的安装探测结果，显示检测到的版本，去除固定的“尚未探测”文案。
- 分别显示安装未检测、已检测 CLI 安装、缺少模型、未找到 CLI、版本探测失败等状态。
- CodeAgent 复用内部模型，不因外部模型字段为空而提示缺少模型。
- Provider 配置保持“接口未检测”，不借用本机 CLI 安装结果作为网络连通性证明。
- 刷新检测失败时清除旧成功状态。
- 包含 0.1.3 的 Windows codeagent.bat、带空格路径和最新 PATH 探测修复。

Native profiles now share the corresponding CLI discovery result and version instead of displaying a fixed unchecked badge. CodeAgent retains its internally configured model. Provider endpoint connectivity remains separate from installation discovery, and failed refreshes clear stale success status.

安装探测仅执行版本命令，不验证登录或模型授权。内部 CodeAgent 的真实推理仍需部署环境验收。安装程序未签名；运行依赖按使用能力单独配置。
