# 0.19.0 — 候选问题人工复核

- 会话和运行实例中的报告支持记录待补证据、确认缺陷、误报，以及对应理由。
- 候选列表显示复核状态，历史可展开并导出，重新打开应用后可继续查看已保存结论。
- 确认缺陷和误报会核对执行证据及原文关联，资料不完整时可记录待补证据。
- 复核理由接入草稿保护，关闭报告后可继续编辑。过期操作会被拒绝，状态更新保留历史。
