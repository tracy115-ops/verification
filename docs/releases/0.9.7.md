# 0.9.7 — 从候选问题直接复核证据

报告新增候选问题列表与四个复核视图：执行证据、用例与原文、执行时脚本、Agent 分析。失败摘要先显示关键错误，完整调用栈按需展开；同一测试方法的请求响应集中呈现，报告备注和验证范围可展开查看。

证据按报告摘要、执行计划摘要及运行/会话/执行 ID 绑定。缺少历史产物时明确提示，不以其他执行结果替代；不会把未批准草稿当成执行时用例。历史设计修订和运行记录使用自己的快照。

本轮是只读复核优化，不改变判定、审批或执行授权，也不会把 Agent 候选自动标为已确认缺陷。普通回归使用之前真实生成、执行的归档；原生验证在新 Release 中打开同一真实历史任务，不重复付费生成脚本。

验证：219 项单元测试、62 项生产界面测试、9 项开发界面测试通过；最终摘要修复后，4 项关联反例及生产报告交互复测通过，格式与 438 个源文件约束通过。0.9.7 本地正式桌面 Release 的报告四标签操作通过，读取此前真实任务，无存储注入、无模型替身。原生首轮发现并修复报告结果摘要与产物包装摘要混淆的问题。详见[原生验收记录与截图](../quality/native-desktop-e2e.md)。内部 CodeAgent、多机及完整升级仍维持原有验收范围。
