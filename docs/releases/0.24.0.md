# 0.24.0 — 多文件 Python SDK

- 测试框架设置可导入包含 `framework.py` 和 `sdk/` 的目录，保存模块文件快照。
- 本地预检逐文件解析源码，执行确认可查看入口和模块源码。计划摘要绑定完整包，模块修改会让旧授权失效。
- 复现资料包含已执行的 SDK 快照；已有单文件计划沿用原摘要。
- Claude 跨组分析省略逐段事件，降低原始协议输出。状态路径引用可还原唯一匹配的标识符格式差异。

依赖由所选 Python 环境提供。当前范围为本地 unittest，新增 SDK 字段需要本版本读取。

已验证生产界面目录导入和重载、前端与 Rust 摘要一致、原生预检和 HTTP 执行。验收使用本地参考目标和既有模型脚本。操作见[本地 Python 工作流](../workflows/local-python-verification.md)，边界见[框架接入检查](../design/framework-admission.md)。
