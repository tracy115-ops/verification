# 0.10.2 — 在软件内预览、恢复保护副本

设置 → 数据管理直接列出最近两份保护副本，可选择任一份导出，或“预览并恢复”。预览会核对副本摘要与业务结构，展示会话、流程运行、CLI 记录、框架和流程草稿范围；取消预览不创建副本、不替换当前数据。

确认从保护副本恢复后，先为当前数据创建并校验保护副本，再恢复已预览的内容并重新载入。保存当前数据失败时停止恢复；等待落盘后再次检查任务与页面状态，尚未开始替换时不允许继续失效操作。恢复前的副本可再次选中以撤回，但仍遵循最近两份轮换，不是永久撤销历史。

所选内容在预览时完整读取并校验，恢复前另存当前数据导致旧副本被轮换时，仍使用已确认的不可变内容。失败后重新读取副本状态，避免显示过期的成功信息。副本列表展示日期与条目数，详情只保留大小和摘要，减少重复信息。

这次增强的是保护副本直接恢复；原有文件导入、个人数据清空和副本独立保留规则不变。当前主仓库仍为 localStorage / IndexedDB；本次不声称恢复跨存储原子化，断电、强杀和物理磁盘满恢复尚待专门验收。

验证：235 项前端单测、71 项生产界面回归、78 项 Rust 测试通过；3 项真实网络/PAC 测试显式跳过。精简详情后复跑 6 项相关交互，中英文及深浅主题的 900×650 预览无横向溢出。

真实本地 Release 窗口先验证会话恢复及撤回，再使用历史真实设计任务和四条 CLI 档案，通过界面导入、创建副本、删除、恢复、重新载入及撤回；完整会话/产物字符串、CLI 记录逐字段与恢复前后清空状态均核对通过。[截图与验证记录](../examples/generated/data-recovery-2026-11-08/README.md)。本轮不重新认证模型推理或安装升级，安装流水线结果另计。
