# 0.8.0

- 会话新增“修改当前设计”，通过真实 CLI 生成因子、场景的增量提议；右侧按条目查看新增/修改及字段差异，人工选择合入或不采纳。
- 提议绑定需求、设计及自身内容摘要，支持过期检测、并发防覆盖、取消和持久化。未解决问题不能合入，保留现有严格来源及映射校验。
- 合入归档旧设计与结果，重新打开覆盖评审，撤销下游用例、脚本、覆盖声明和执行确认。历史产物有只读入口。
- 修复旧重试时间导致修订评审立即过期，取消固定 10 次设计修订计数；减少重复等待信息及差异展示中的无效空列。

181 项单测、38 项生产前端交互回归通过。真实桌面两次 Codex 调用分别验证新增合入和修改拒绝，刷新后保留，旧报告内容不变。见[验收记录](../research/design-proposal-0.8.0-validation.md)。

本轮为个人设计提议，常规评审工作区和共享项目提议合入仍待完善；未重新执行新增设计，不代表内部 CodeAgent 或安装升级已验收。
