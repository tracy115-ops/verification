# Verification Workbench 0.7.0

- 在场景、分批设计、用例和脚本任务中加入共用深层调查指引，关注状态序列、幂等作用域、拒绝后的状态、守恒关系和并发最终状态；保留需求依据与原有评审。
- 新增可复现的订单状态旅程验收。真实 Codex 生成 15 个方法，经正式原生预检/执行捕获六个独立缺陷变体，正确参考零失败；多轮重放一致。
- 保存原文、公开回复、方法映射、摘要和请求/响应复现记录，增加归档完整性检查。
- CI 和打包只重放固定脚本；重新生成必须显式指定模型，不自动调用付费模型。

[规划](../design/deep-blackbox-discovery.md)、[验证记录](../research/deep-blackbox-validation.md)已归档。自动状态空间探索与复现缩减尚未实现；受控样例结果不代表用户项目发现率。内部 CodeAgent 和桌面点击链路仍需真实环境验收。
