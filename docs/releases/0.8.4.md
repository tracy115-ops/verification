# 0.8.4

- 修复多个 Claude 安装实例被统一解析为 PATH 第一个入口的问题。每个原生 Agent 可指定 CLI 启动文件，Claude 可指定已有的 `CLAUDE_CONFIG_DIR`。
- 显式 `.cmd` / `.bat` 保留包装脚本中的环境配置；指定路径无效时立即返回稳定错误，不回退到其他实例。
- 普通对话、需求分析批次、场景分析、用例生成与设计补充统一传递实例绑定；已创建流程和节点重试沿用冻结快照。
- 明确区分 PATH 安装探测与指定实例的调用验证。认证失败提示包含第三方 Provider 配置，模型名称本身不配置认证。
- 工作流导出剔除机器上的启动路径和配置目录；本地配置与历史调用记录保留绑定。

旧配置无需迁移，未绑定路径时保持自动发现。配置目录只传给子进程，不复制凭据，不覆盖用户全局配置。原生 CLI 的环境变量优先级仍然生效。

验收范围见 [多实例验证记录](../research/cli-instances-0.8.4.md)。
