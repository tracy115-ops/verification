# Verification Workbench 0.4.1

- CodeAgent / Claude 顶层 error 事件与失败 result 现在提取稳定错误分类，不再忽略后一直等待超时。明确的协议失败会停止受管进程；原始错误信息不写入日志。
- 超时提示区分没有输出、只有状态没有正文、已有部分正文但未完成，以及已完成但进程未退出。
- 诊断补充 protocol_records、unknown_records、last_event、public_text_bytes。事件类型仅使用预设白名单；未知类型统一记录 unknown，不保存原始内容或任意事件名。
- system 初始化、API 重试和 Hook 状态分别标记，帮助区分可能停滞的阶段；状态不等同于内部模型工作证明。

验证使用受控进程：输出认证错误后持续运行会立即失败并终止；只输出初始化后等待会得到无正文超时分类。内部 CodeAgent 的实际超时根因尚未确认，仍需目标环境日志或同请求的直接 CLI 对照。
