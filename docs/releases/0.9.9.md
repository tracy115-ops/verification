# 0.9.9 — 调用前准备检查

会话输入框新增默认折叠的“调用前检查”，显示本次保存版本、实际执行步骤、各节点使用的 Agent、模型、CLI 实例和配置来源。范围预览与实际运行共用节点选择规则，避免设计模式被未使用的执行节点配置误拦截。

缺模型、失效 Agent、非法 Python 命令或目标地址格式，会在创建任务之前阻止按钮和回车发送，保留原 Spec。CodeAgent 继续使用内置模型配置。`/run` 同样受检，错误指令不会导致界面崩溃。

短对话状态仅复用本次应用会话里精确匹配当前配置的检查结果。未测试或测试失败会明确提示，不自动发起付费请求；短对话通过也不认证结构化流程兼容性。设计模式明确提示不生成脚本、不执行测试；框架格式校验不表示 Python 可用或目标可达。

窄窗口展开检查时，内容随视口限制高度并在内部滚动，发送栏保持可见。补充中英文、深浅主题的 900×650 视口断言及截图复查。

验证：225 项单测、64 项生产界面回归、格式/类型/版本一致性及源码约束通过。首轮界面回归曾因同时重建 dist 导致旧资源 404，已固定产物后完整重跑通过；最后的删除 Agent 边界补丁通过单测，并在重新构建后复跑准备清单界面用例。本地 0.9.9 Release 原生窗口与原 Tauri IPC 验证通过：明确选用设置文件、真实 Claude 短测成功，刷新清除旧短测结果，新面板使用实际所选模型与来源，缺模型时禁止调用。

本次原生验证覆盖配置与准备清单，没有重新执行完整黑盒脚本流程。此前完整原生流程证据见 [native-desktop-2026-11-06](../examples/generated/native-desktop-2026-11-06/README.md)。CodeAgent 内部环境、SSH / WSL 和两台物理机器协作不在本次验证范围。
