# Verification Workbench 0.4.0

- 支持运行中切换、搜索和新建会话，并在多个会话中并发执行对话或流程。
- 每个会话独立维护运行状态、流式输出、错误与取消；停止当前会话不影响其他会话，回复与流程产物写回各自所属会话。
- 会话列表标记后台执行状态；同一会话仍防止重复发送，运行中会话禁止删除，其他会话可正常管理。
- 原生 CLI 最多 8 个调用并发，Python 执行最多 8 个并发；不提供跨会话的被测系统数据隔离，测试同一有状态目标时需使用独立测试身份与数据。
- 任一会话运行期间，全局更新安装、数据恢复和退出提示仍保留保护。

验证包含两个独立会话同时发送、流式输出隔离、切换、独立取消与结果归属的 Hook 回归；生产构建界面回归验证真实切换和发送操作（离线 IPC 夹具）。原生任务保留与取消测试覆盖独立会话、同会话重复、并发上限及 Python 独立任务。此验证不代表内部 CodeAgent 并发模型额度或限流策略已认证。
