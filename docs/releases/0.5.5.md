# Verification Workbench 0.5.5

- CLI 启动诊断记录部分消息流是否启用、会话持久化参数及代理来源；不保存代理地址、模型名和凭据，不改变原有代理策略。
- 进度诊断记录输入是否成功写入并关闭管道、初始化事件数和最近三条受控事件类型。需求、场景、用例等任务在启动日志中区分操作类型。
- 仅收到初始化事件时使用独立超时提示；不将写入成功误报为模型已经收到请求，不提前停止长分析。
- Release 附带 cli-diagnostic.exe，以同一原生驱动执行短请求对比，无须安装 Rust 或额外配置 CodeAgent 模型。

本地 Windows bat 回归覆盖五条 init 后接收大于 32 KB 的中文 JSON。它只验证管道和协议，不认证内部 CodeAgent 的真实模型推理。本次改动补齐定位手段，尚未确认用户内部环境十分钟等待的具体原因。
