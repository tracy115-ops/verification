# Verification Workbench 0.6.0

- 需求解析与场景设计的大请求自动分批，单次序列化输入控制在 24,000 UTF-8 字节以内；小任务沿用原流程。
- 原文核心片段连续覆盖全部 Spec，保留边界上下文和 Markdown 标题路径。原文引用继续在完整 Spec 中检查，合并结果仍需人工确认。
- 场景按已确认需求分组生成，并检查需求组的两两关联。组间场景必须同时关联两组需求；两两检查不代表所有高阶组合已经覆盖。
- 每批保存输入签名和结果摘要，失败、刷新或取消后可以继续，跳过已完成批次。手动修复引用只完成当前批次，不绕过剩余分析和评审。
- 右侧节点和中间调用记录显示批次进度与组间检查；无新增需求的批次使用简短说明。

分批会增加短请求次数，目标是降低单次输入与生成压力并保存进度，不保证总耗时必然缩短。本机未安装内部 CodeAgent，尚不能证明其初始化后等待问题已解决。
