# 0.12.0 — 流程库与设计缺口检查

## 新增与修复

- 编排页新增流程库：新建、复制、重命名、搜索、切换和删除模板。每个模板独立修订，未保存修改有保护。
- 会话独立记忆流程选择；历史任务保留调用快照。删除模板不会删除历史产物，缺失的选择不会静默调用另一流程。
- `/run ID` 调用前检查与实际调用使用同一流程；新建流程从当前支持的通用测试模板开始，保留现有操作类型和 Agent 绑定接口。
- 修复设计路径末端新增人工复核可能未进入实际运行的问题。
- 覆盖矩阵增加设计缺口检查：无场景的因子水平、无用例的场景、待澄清需求和设计缺口可逐项查看及跳转补充。
- 旧单流程自动兼容加载；备份/恢复支持完整流程库。导入创建独立草稿，不覆盖已保存模板或未保存编辑。

## 范围

结构映射不代表业务组合、时序和异常覆盖充分，也不代表执行通过。当前运行引擎支持已定义的测试操作与人工复核；尚未提供任意自定义 Agent 节点运行协议。个人主存储事务化迁移、真实多设备协作验收及独立题目的真实 Agent 盲测继续按[实施顺序](../design/workflow-library-and-quality.md)推进。

## 兼容性

流程数据沿用原键，以版本化流程库容器一次保存。支持读取旧单流程及旧备份；旧版应用不能读取新流程库，降级前需恢复旧备份。删除模板后，引用它的会话需要重新选择流程。

本版本按 GitHub Release 流水线构建 Windows Release 安装包，包含来源版本和摘要；发布状态以 Actions 结果为准。操作验收见[验证记录](../research/workflow-library-validation-2026-11-09.md)。
