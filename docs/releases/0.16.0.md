# 0.16.0 — 框架接入静态检查

- 设置中导入或编辑 Python 框架后，可检查解释器版本、语法、源码规模和 `BlackBoxCase` 入口声明。
- 明确问题默认展开，行号可回到源码；动态入口和复位/证据线索明确保留为未确认。
- 支持取消、进程时限和目录清理；源码或 Python 命令变化后不沿用其他版本的检查，取消及迟到响应不能覆盖新状态。
- 已知框架问题在完整流程调用前阻止发送并保留 Spec；仍可先做设计评审。检查报告随新运行固化。

静态检查不会导入框架、运行测试或访问目标；不能代替依赖检查和授权执行。当前执行器仍是单文件 unittest。检查结果为当前应用会话缓存，重载后需重新检查；未检查状态仍可走原有执行预检。详见[设计与使用说明](../design/framework-admission.md)及[专项验收](../research/framework-inspection-validation-2026-11-17.md)。
