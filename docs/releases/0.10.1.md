# 0.10.1 — 升级前自动保护个人数据

在在线升级中确认“安装并重启”后，先创建并验证个人数据副本，再交接安装器。准备过程显示独立状态，可取消；取消后允许正在进行的原子写入结束，但不会启动安装器。离开页面也会停止后续交接。备份失败会显示具体原因并保留已下载安装包供重试。

原生安装 IPC 独立核对最近副本 ID、摘要和 SQLite 完整性；缺少、过期或损坏的副本不能通过。副本操作加入现有安装活动互斥，避免同一应用在安装交接时继续轮换副本。现有安装包摘要验证、任务/托管服务检查和系统代理逻辑保留。

副本仍保留最近两份，范围为已保存的个人会话、流程、框架及公开 CLI 记录，不含团队项目、磁盘执行证据或 CLI 认证文件；没有自动恢复、独立容灾或跨存储原子快照。此保护适用于 0.10.1 运行时发起的后续升级，旧版首次升级到本版仍按旧版逻辑，可先手动创建或导出副本。

验证：231 项前端单测、78 项 Rust 测试及 68 项生产界面回归通过；3 项真实网络/PAC 测试显式跳过。取消状态调整后又复跑 5 项升级/数据管理交互。真实本地 Release 窗口已核对原始 Tauri IPC：缺少副本及错误摘要被拒绝；真实 SQLite 副本通过核对后继续到安装包就绪检查，因未下载更新而停止，没有启动安装器。副本创建、刷新、导出与原数据不变也已复验。

CI 安装冒烟增加实际副本创建和安装前后文件摘要比对；安装/重启在一次性 runner 执行，结果以本版本 Actions 为准，不将本地门禁验证描述成完整升级重启通过。
