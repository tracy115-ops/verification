# 0.17.0 — 场景引用诊断与流程状态

- 因子引用超出关联需求原文时，显示相关因子和需求 ID。重试会附带诊断，保留已确认需求和原始回复。
- 旧任务若保留了对应的公开 CLI 回复，可在重试时重建因子引用诊断。产物仍须通过原有引用校验和覆盖评审。
- 发送后清空输入框时，正在运行的任务不再显示下一次调用的准备提示。空白草稿会明确提示输入 Spec。
- 单次分析启动后仅展示实际任务状态。分批分析继续显示已保存的批次。
