# 0.15.0 — 桌面会话事务存储

- 数据管理新增会话迁移入口：先保护当前数据，确认来源后启用 SQLite。原浏览器会话保留，已有数据库只连接、不自动覆盖合并。
- 启用后，会话、输入草稿、运行和内嵌产物从 SQLite 主读写；按提交版本拒绝过期实例写入。
- 写入失败保留内存内容，提供重试与恢复副本导出；启动失败明确报错，正常关闭及备份等待提交完成。
- 个人数据导出、清空和恢复遵循当前会话存储来源，避免误导出过期的浏览器副本。

这是分阶段迁移。流程库、全局配置、CLI 日志和人工表单草稿尚未迁入该库。详见 [ADR 0005](../adr/0005-transactional-conversation-primary.md)。
