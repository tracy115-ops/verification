# 0.8.1

- 人工评审暂停流程预算；隔夜等待、刷新后确认可继续，自动处理仍受剩余预算及节点超时限制。旧待评审任务首次确认时恢复预算。
- 确认、澄清和恢复操作绑定目标会话，异步计算前后检查任务版本；取消或陈旧页面不会推进后继步骤。
- 取消脚本澄清固定两次限制；修复等待过久后脚本澄清/引用恢复立即继承旧超时的问题。
- 个人数据加载及保存拒绝重复会话/运行 ID 和跨会话运行归属，非法数据不会覆盖原存储。

详见[恢复契约](../design/review-recovery-budget.md)、[验收记录](../research/reliability-0.8.1-validation.md)和[企业化清单](../roadmap/enterprise-readiness.md)。

191 项单测、39 项生产界面回归及完整检查通过；真实桌面恢复旧覆盖评审，经 Codex 生成更新用例并保存到下一确认点，历史保持不变。

数据兼容：新版本可读旧会话；保存暂停字段后的记录不兼容旧版严格加载器，降级需恢复升级前备份。
