# 0.10.3 — 页面连续性与紧凑配置

返回设置会保留上次分区，Agent 和测试框架输入在导航后保留；多个实例和框架草稿独立，新建框架可取消。返回资产页、运行记录与协作页面时，保留当前筛选、项目步骤和场景草稿，资产仍按会话及运行隔离。

压缩 CLI 探测卡片，修正已有任务显示新会话欢迎语的问题，并补充导航选中语义与对话框清理。隐藏页面释放订阅；升级和恢复操作页离开时继续执行原有取消逻辑，不在后台保留安装确认。

为安装打包增加仅针对临时 bundler HTTP 错误的有限重试，处理上一版本编译成功后 NSIS 下载 HTTP 504 的失败；普通编译或配置错误直接返回失败。

本轮检查范围、复现与真实/模拟边界见[页面验收记录](../research/page-continuity-audit-2026-11-08.md)。这次没有认证内部 CodeAgent，也不将历史真实 CLI 档案展示视为新的模型推理验收。

本地验证：235 项单测、73 项生产界面回归、4 项真实协作回归、78 项 Rust 测试通过；3 项真实网络/PAC 测试显式跳过。实际 Release 窗口导航专项通过；2 项 Python 工作流测试及六个深层缺陷变体回归通过。另有 3 项打包重试契约验证。
