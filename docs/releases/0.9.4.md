# 0.9.4 — Claude 独立设置文件接入

## 行为变化

终端通过 `--settings` 使用独立配置时，应用此前仍加载默认设置，导致终端可用、桌面认证失败。现在在设置 → Agent 与 Provider → Claude → CLI 实例中选择已有可信设置文件并保存，模型读取、认证来源诊断、短测试、会话与新流程均使用该文件。支持文件选择，不需要手抄路径；配置目录仍可单独绑定。

修改绑定使旧连通结果失效，历史运行保留其快照。只保存路径，不复制密钥、不修改默认设置、不自动恢复备份。共享工作流移除本机绑定。

## 验证证据

- 清除子进程临时 Anthropic/OAuth 认证变量，使用本机现有独立文件，经应用相同 Rust `run_turn` 驱动调用真实 Claude：`glm-5.3-flash` 完成固定标记短对话。
- 相同条件下进行黑盒接口需求提取：约 72 秒完成，返回 10 条需求，全部原文引用精确匹配输入。该测试覆盖独立文件接入与需求提取，不代表完整执行测试流程或任意长 Spec 均已通过。
- Windows 包装器回归验证启动文件、配置目录及含空格设置文件作为独立参数传递；模型读取与认证诊断不返回凭据。
- 212 项前端单测、41 项 Agent Rust 测试、59 项生产界面回归、桌面编译和 Clippy 检查通过。另通过开发版实例绑定交互；界面回归覆盖保存/重载、请求绑定和 900/1500 像素下深浅主题。

当前原生桌面 UI 自动化宿主不可用，未将浏览器 IPC 模拟回归表述为已安装桌面窗口的完整点按验收。真实 CLI 证据来自应用共用 Rust 驱动，而非模拟返回。
