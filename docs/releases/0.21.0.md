# 0.21.0 — 候选问题应用内复跑

- 报告内直接准备独立复跑，沿用已评审的完整脚本，重新预检并确认执行。
- 会话、右侧和运行实例展示实际证据及按方法累计的复跑观察，原报告和人工复核保持不变。
- 停止或失败后可重新预检、确认并执行；保留原执行计划与失败记录，不复用旧授权。
- 继承的设计产物明确标识并禁止直接修订，避免将复跑变为另一份测试设计。

[设计说明](../design/reproduction-runs.md)记录操作与统计边界。[验收记录](../research/reproduction-run-validation-2026-11-22.md)包含真实 Windows 桌面、Python/HTTP 执行及刷新恢复。逐次复跑不调用模型；本版尚未提供无人值守批量复跑或最小化器。
