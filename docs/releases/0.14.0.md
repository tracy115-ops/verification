# 0.14.0 — 人工与 Agent 用例修订

- 验证资产支持新增、编辑和复制用例，分三步填写关联、步骤断言及修改原因；保存后直接定位用例。
- 覆盖缺口和用例评审支持回到原会话请求 Agent 增量补充，逐条查看差异后合入或拒绝。
- 用例修订保留已确认的需求与场景，重新打开用例评审；旧脚本、覆盖声明、执行授权和结果失效，保留修订历史。
- 用例草稿支持关闭及跨会话恢复，基线变化时阻止覆盖。未解答问题、引用错误及过期提议不能直接合入。

详见[方案](../design/case-revision-and-proposals.md)与[验收记录](../research/case-revision-validation-2026-11-09.md)。内部 CodeAgent 的实际推理仍需目标环境验证；本期离线协议测试不作为其认证或模型连通证明。
