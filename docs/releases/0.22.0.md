# 0.22.0 — 可评审的场景旅程

- 场景可附带版本化的多步状态路径，明确前置条件、操作、逐步观察和原文依据。
- Agent 设计、分批合并和增量提议保留旅程，人工可逐步骤编辑并重新评审。
- 校验状态连续性、步骤唯一性、需求归属和原文引用，兼容已有无旅程场景。
- 场景及用例评审展示同一条旅程；修改后归档并使下游用例、脚本及执行授权失效。
- 修复预检误拒绝 Python 模块/类文档字符串的问题，保持对顶层执行表达式的限制。

[设计与范围](../design/scenario-journeys.md)。本版提供可评审路径，不是自动状态空间搜索；结构有效不代表语义完整或测试已执行。

[验收记录](../research/scenario-journey-validation-2026-11-22.md)包含新模型生成的限定旅程、真实 Python 正确/缺陷对照，以及大题目输出上限失败的边界。
