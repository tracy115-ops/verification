# 0.10.4 — 模型配置读取的离页恢复

修复 0.10.3 导航状态保留后的一项异步边界：读取已有模型配置期间离开设置，旧读取结果会被废弃，但返回后“检测中”状态没有复位，导致无法再次读取。现在返回设置或切回该 Agent 时恢复读取按钮，迟到的旧响应仍不能覆盖新的结果。

新增交互回归先在未修复版本复现失败，再确认修复后通过；同时验证重新读取成功后，旧响应返回不会替换当前候选模型。该测试使用延迟 IPC 契约，不调用模型、不表示重新认证 CLI。其余页面连续性与真实桌面验收范围见[页面检查记录](../research/page-continuity-audit-2026-11-08.md)。

本地验证：235 项单测、11 项相关生产界面回归、版本/格式/源码约束及构建通过；重新编译实际 Release，在原始 IPC 窗口复核六个主页面、七个设置分区和跨页状态，并从更新页核对版本为 0.10.4。完整远端打包、全套界面及安装冒烟由该标签流水线执行，结果单列。
