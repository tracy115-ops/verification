# 0.9.8 — 配置来源选择反馈

选择 Claude 设置文件后保留扫描列表，突出当前选中项，分别显示尚未短测、短测通过及短测未通过，避免把扫描发现当成正在使用或已经认证成功。

新增“选用并测试”：明确点击后保存所选文件，并以该已保存配置调用真实 CLI。提示可能产生费用，未保存模型时禁用。取消按钮与第三步短测共享同一个请求；切换配置、离开页面会取消旧调用，旧结果不能覆盖新配置。

扫描仍只读取文件元数据，不会自动启用备份或覆盖默认 settings 文件。短测结果仅在本次应用会话保留，刷新后保留绑定但不继承绿灯。

验证：219 项单测、63 项生产界面测试、9 项开发界面巡检通过；新增源发起短测与第三步共享取消的交互回归通过。真实 CLI 前端集成短测，以及本地 0.9.8 Release 的原生窗口/原 Tauri IPC 操作均通过：明确点击后绑定文件、返回正确标记、保留选中行，刷新恢复绑定且清除旧测试结果。首轮本地构建未开启正式资源协议，验收失败；按正式打包的 `tauri/custom-protocol` 重建后通过，未用开发页面冒充 Release。
