# Verification Workbench 0.5.0

- 普通对话新增上下文选择：最近内容、仅本条消息、全部完整消息。默认历史窗口最多 20 条并控制在约 32 KiB，最新消息保持完整。
- 本次未携带旧消息时明确提示，原始聊天记录保留；可切换全部历史恢复完整输入。上下文裁减不保留失去对应用户消息的开头助手回复。
- 需求解析请求中的重复 Spec 改为引用 sourceSpec，只发送一份原文；原始任务和产物不变。
- CLI 运行时每 15 秒写入 cli.progress，可在日志页刷新查看事件阶段、输出量和最后输出时间，不再只能等到超时才检查。

用户反馈新会话回复较快，旧会话更慢，提示需要优先检查输入上下文。模型或网络的具体停滞原因仍未认证；本版没有因此改变 CLI 代理策略。约 32 KB 的请求没有超过工作台输入上限，不能仅凭大小判定超时根因。

验证：125 项前端测试、28 项驱动测试、4 项生产界面交互及 2 项原生 Python 工作流集成测试通过；静态检查和生产构建通过。界面与 Agent 回归使用受控夹具，不代表内部环境的响应耗时已认证。
