# 0.10.0 — 本机数据保护副本

M2 数据可靠性的首批交付：设置 → 数据管理新增创建、重新校验和导出保护副本。最近两份快照独立写入本机 SQLite，日常读写继续使用现有个人存储，不自动迁移或恢复。

快照复用现有个人备份范围，包含已保存会话、流程、框架及公开 CLI 记录，不包含团队服务数据、磁盘执行证据或 CLI 认证文件。运行任务或有未保存流程时禁止创建；采集期间来源发生变化则拒绝写入。

写入、两份轮换和校验在同一事务内完成。SQLite 完整性或摘要异常、未知数据库版本会保留文件并停止写入。每份最多 20 MiB；数据库文件超过 128 MiB 停止写入。界面显示快照时间、条目数、大小和摘要，失败后不沿用旧成功提示。

可导出经过摘要与业务结构校验的最近副本，通过原有“导入个人数据”确认后恢复。副本不表示当前最新数据，也不代表跨设备容灾；两份快照共用一个数据库文件。主仓库迁移、自动升级前备份、断电/强杀恢复尚未交付。

保护副本独立保留，清空或导入当前个人数据不会删除副本；界面及操作确认中明确提示。暂时被其他连接占用的数据库不会误报为损坏。

验证：228 项前端单测、65 项生产界面回归及 76 项 Rust 测试通过；3 项真实网络/PAC 测试显式跳过。新增中英文、深浅主题窄窗口检查。真实本地 Release 窗口使用原始 Tauri IPC 创建 SQLite 文件、刷新重读、导出 JSON，并核对来源数据未变化。没有模型调用、物理磁盘满、断电或强杀验证；界面回归中的损坏提示为离线夹具，数据库损坏、占用恢复和事务失败由真实 SQLite 单测覆盖。
