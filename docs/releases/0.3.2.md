# Verification Workbench 0.3.2

- 修复流程节点设置超过 600 秒仍被前端截断、原生 CLI 请求又拒绝超过 600 秒的问题。
- CLI 接受 1 至 86400 秒，与编排输入上限一致。流程总截止时间仍约束实际调用，取消和进程清理机制保留。普通对话仍保持原有 300 秒时限。
- 诊断新增请求输入字节数、实际时限、调用耗时、stdout 字节数和最后输出距结束的时间；不记录需求正文或原始 CLI 输出。stdout 可能包含协议记录，字节数不代表模型已成功分析。

已有节点默认值不会自动改变，历史运行固定原快照。复杂 Spec 可在流程编排中将“解析需求与验证点”设为 1800 秒后保存，并发起新运行。延长时限不能保证解决模型网络、等待交互或协议不兼容问题。
