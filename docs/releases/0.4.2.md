# Verification Workbench 0.4.2

- 在线安装交给独立的原生更新进程：复制到更新缓存后启动，等待旧进程退出，再次校验安装包并运行安装器。
- 更新进程等待安装器退出并记录退出码，成功后负责重启应用；不再把安装器请求已接受当作安装成功，也不依赖 NSIS 的自动重启插件。
- 更新阶段保存到 updates/last-install.json；下次启动将阶段、退出码、目标版本写入诊断日志 update.last_result。目标版本不一致会记录 version_mismatch，启动成功后才记录 completed。
- 发布流水线运行同一更新进程，验证等待旧应用、安装、重启、存活和用户目录标记保留。

用户环境的具体失败原因尚未确认。旧版执行在线升级仍使用其旧交接代码；若旧版升级失败，需要手动安装本版一次。测试覆盖同版本覆盖安装，不代表跨版本业务数据迁移已认证。
