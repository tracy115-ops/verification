# 0.23.0 — 有界交叉分析

- 跨需求组检查按每侧最多四条需求分块，保留原计划的全部跨组需求配对。
- 每条细分检查独立保存，继续分析受当前批次预算约束，剩余检查保持可见。
- 对局部设计已完成且尚无交叉成果的旧任务，校验旧签名和缓存摘要后迁入细分计划；已有交叉成果的旧任务保持原计划。
- 预算区展示细分说明和按批次展开的需求范围。
- 安装扫描复用启动错误分类，流式诊断细分正文、思考、工具参数与消息生命周期。

新增计划字段需要本版本读取，降级请使用升级前的数据保护副本。

本地通过 335 项单元测试、六项原生工作流集成及生产界面检查。真实大题目的首条细分交叉检查完成并保存，耗时仍约 8 分 40 秒，剩余三条尚未实测完成。详见[验收资料](../examples/generated/bounded-cross-2026-11-24/README.md)。
