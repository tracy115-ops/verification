# 0.15.1 — 保留重试期间的存储保护

- 修复会话保存重试时提前清除失败状态的问题：数据库确认提交前，继续保留告警并阻止新的 Agent 任务。
- 即使内容已改回之前的值，失败后的重试仍校验提交版本，不能跳过冲突检查。
- 补充显式浏览器回退及重新连接已有 SQLite 的界面回归，不自动覆盖或合并两边数据。

数据库 Schema 和迁移路径与 0.15.0 一致。使用方法见[会话事务存储](../workflows/conversation-storage.md)，验证范围见[验收记录](../research/conversation-storage-validation-2026-11-12.md)。
