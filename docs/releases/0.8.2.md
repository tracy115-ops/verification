# 0.8.2

- 正确识别 `Not logged in · Please run /login`，返回认证错误，不再落入通用失败。该分类用于原生失败记录，不把普通讨论中的相同文字当作登录失败。
- 普通对话失败改为消息级处理提示，移除“产物已保留、重试当前步骤”的流程提示；登录/模型问题可直接打开 Agent 设置。
- 普通回复保存并显示实际 CLI 和模型，切换 Agent 或刷新后仍可核对原调用；调用信息包含稳定错误码和调用 ID，不复制原始提示词。
- CodeAgent 模型访问错误指向其内置配置，不要求填写应用中的模型 ID。

用户已确认同机终端也会提示未登录或模型不可用：本次修复分类、定位和恢复交互，不能代替原生 CLI 登录或授予模型权限。版本探测仍仅证明已安装，不证明已认证。

新版本兼容旧消息。含新增 CLI 元数据的会话不兼容旧版严格加载器，降级应使用升级前备份。

192 项前端单测、37 项原生运行时测试、43 项生产界面回归通过，见[验收及截图](../research/cli-failures-0.8.2-validation.md)。
